# AI 台词搜索

已确认：保留搜索框和卡片，不做聊天。原文结果优先，补充标为“意思相近”的真实字幕；无关联时返回空结果。

实现顺序：
1. 测试候选召回和模型输出校验：拒绝虚构 ID、重复和低相关结果。
2. Cloudflare Worker 保存 DeepSeek secret；扩展双语搜索词，召回最多 60 条字幕，再由模型筛选最多 8 条。
3. 前端立即显示原文匹配，异步补充语义结果，单独展示忙碌/失败状态，取消旧请求，分页仍只针对原文。
4. 限制 120 字查询、请求超时、每 IP 每分钟 5 次和每节点每分钟 20 次未缓存请求；缓存有效结果 24 小时。这不是严格的全球费用上限。
5. 单元测试、构建、线上原文/语义/无关场景验证后发布。

范围限制：本版通过双语扩词召回后重排，不是全库向量检索，可能遗漏隐含语义。模型原因是辅助说明，原台词和片段不改写。API 故障不会阻止原文搜索。
